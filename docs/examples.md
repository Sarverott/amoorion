# Examples

Jupyter notebooks from [`examples/`](../examples/), shown as they were last
run. They use the `dryrun` platform and fakes, so they post nowhere; open
them in Jupyter or build them with marimo (`uv run task examples:build`).

```{toctree}
:glob:
:maxdepth: 1

examples/*
```

Beside the notebooks, in the repository: `examples/advanced-usecases/` (one `run.py`
each, run by the tests) and `examples/spaces/` (Gradio and Streamlit apps, ready to be
Hugging Face Spaces, on `dryrun` only).
