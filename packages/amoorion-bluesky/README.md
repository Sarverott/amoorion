# amoorion-bluesky

Bluesky plugin of [amoorion](https://github.com/Sarverott/amoorion): post (links and tags as
clickable facets), read, reply and delete (only its own posts) through the AT Protocol.

Secrets in amoorion's vault: `bluesky/username` (handle or e-mail),
`bluesky/password` (an [app password](https://bsky.app/settings/app-passwords),
not the account's), optional `bluesky/uri` (the PDS, default
https://bsky.social).
